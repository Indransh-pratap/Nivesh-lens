# API contract

All FastAPI endpoints are prefixed with `/api`. Portfolio endpoints require the signed internal request generated by the Next.js server proxy.

| Method | Endpoint | Request | Success | Errors |
| --- | --- | --- | --- | --- |
| GET | `/api/health` | none | `{"status":"ok","database":"connected"}` | `503 DATABASE_ERROR` |
| GET | `/api/portfolios` | authenticated | array of portfolio responses | `401 UNAUTHORIZED` |
| POST | `/api/portfolios` | `{"name":"My Portfolio"}` | `201` portfolio response | `401 UNAUTHORIZED`, `422 VALIDATION_ERROR` |
| GET | `/api/portfolios/{portfolio_id}` | authenticated | portfolio response | `401 UNAUTHORIZED`, `404 PORTFOLIO_NOT_FOUND` |
| DELETE | `/api/portfolios/{portfolio_id}` | authenticated | `204` | `401 UNAUTHORIZED`, `404 PORTFOLIO_NOT_FOUND` |

Portfolio response:

```json
{
  "id": "UUID",
  "name": "My Portfolio",
  "total_value": 0,
  "created_at": "2026-08-15T00:00:00Z",
  "updated_at": "2026-08-15T00:00:00Z"
}
```

Errors have this consistent shape:

```json
{"error":{"code":"PORTFOLIO_NOT_FOUND","message":"Portfolio not found"}}
```
